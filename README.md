# 🏋️ FitLog - Workout Library Application

A modern and responsive **Workout Library web application** built with Next.js and TypeScript. Users can explore different workouts, view detailed workout information, add exercises to **Today's Plan**, and save workouts for later. The application uses Context API and LocalStorage to maintain workout selections even after refreshing the page.

## 🛠️ Technologies Used

* **Next.js** – React framework for building the application
* **React** – Component-based UI development
* **TypeScript** – Type-safe JavaScript development
* **Tailwind CSS** – Responsive and modern UI styling
* **Context API** – Global state management
* **LocalStorage** – Persistent client-side data storage
* **React Toastify** – Toast notifications
* **React Icons** – UI icons

## ✨ Key Features

### 1. 🏋️ Workout Library

Browse a collection of workouts with useful information such as workout name, muscle groups, difficulty, duration, equipment, calories burned, sets, reps, and rating.

### 2. 📋 Workout Details

View complete information about an individual workout on a dynamic details page, including descriptions and step-by-step instructions.

### 3. 📅 Today's Workout Plan

Add workouts to **Today's Plan** with a maximum limit of **5 workouts**. Duplicate workouts cannot be added.

### 4. 💾 Save for Later

Save interesting workouts for later and access them from a separate saved workout list. The application prevents the same workout from being saved multiple times.

### 5. 🔄 Persistent Data & Notifications

Workout selections are stored in **LocalStorage**, so the data remains available after refreshing the browser. **React Toastify** provides feedback when workouts are added, removed, saved, or when an invalid action is attempted.
